# Páginas futuras

Para manter o mesmo rodapé funcional em toda nova página, inclua antes de `</body>`:

```html
<footer class="site-footer" data-site-footer></footer>
<script src="site.js"></script>
<script src="page-shell.js"></script>
```

O arquivo `page-shell.js` mantém os links, redes sociais, aviso de afiliados e copyright em um único lugar.
