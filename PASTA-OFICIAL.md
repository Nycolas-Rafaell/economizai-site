# Pasta oficial do Economizai

Esta é a única pasta oficial para desenvolvimento, execução e versionamento do projeto.

- Edite os arquivos somente aqui.
- Inicie o site por `INICIAR-ECONOMIZAI.cmd` ou `npm run dev` nesta pasta.
- Faça commits e envios ao GitHub somente a partir desta pasta.
- `.env`, `.ml_tokens.json`, `node_modules` e logs locais não são enviados ao GitHub.
